## Acceptance criteria

- A user can select two distinct fixture-backed ETFs and every comparison field updates side by side.
- A deterministic explanation identifies material differences without giving investment advice.
- Source URLs, field-level as-of dates, and the data-freshness/non-advice disclaimer are visible.
- Same or invalid selections are clearly reported.
- The app is keyboard-usable and responsive.
- The app starts and tests pass from clean Python commands with no secrets, network dependency, or backend.

## Current architecture

- Python is the source of truth for models, fixture loading, validation, comparison, formatting, explanations, CLI commands, static serving, tests, and browser smoke checks.
- `browser-data.json` is generated by Python and commits all display-ready comparison outcomes for the static app.
- The remaining JavaScript is a narrow browser adapter: fetch local generated JSON, attach selection events, and render DOM nodes. It contains no comparison, validation, formatting, fixture-schema, server, or test logic.
- Static HTML/CSS and browser adapter assets are duplicated for repository browsing and installed-package serving; Python tests require exact byte equality.
- No backend, database, authentication, live trading, portfolio advice, Pyodide, persistent agents, production deployment, or orchestration service was added.

## Python commands

    PYTHONPATH=src python -m agentic_project_builder validate-fixtures
    PYTHONPATH=src python -m agentic_project_builder build-browser-data
    PYTHONPATH=src python -m unittest discover -s tests_python -v
    PYTHONPATH=src python -m agentic_project_builder serve
    PYTHONPATH=src python -m agentic_project_builder check-browser

The browser check uses Chrome DevTools Protocol directly from the standard-library Python implementation. It verifies the initial SPY/QQQ rendering, same-selection validation, VTI/QQQ rendering, reload behavior, console/runtime errors, network failures, and HTTP error responses.

Historical Node validation/test/server/browser-check commands were removed after Python parity was established. No release or deployment is attempted; Veritas and human approval remain separate gates.
